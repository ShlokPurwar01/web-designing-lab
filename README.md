# Web Designing Lab — Shlok Purwar

B.Tech CSE-DS practical work for the Web Designing Lab.

## Experiments
1. GitHub repository setup, branches, merging and GitHub Pages
2. Personal portfolio webpage using HTML, CSS and Bootstrap
3. Dynamic to-do list using JavaScript and DOM manipulation

6. Responsive blog website using media queries and Bootstrap
7. Single-page notes application using React.js
