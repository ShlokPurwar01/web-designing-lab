# Experiment 7: React.js Notes App

## Aim
Develop a single-page application using React.js that allows users to view, add, update, and delete notes.

## Resources Used
- HTML
- CSS
- JavaScript
- React.js
- Web browser

## Files
- `index.html` — page structure and React script imports
- `style.css` — responsive layout and note styles
- `react.js` — React components and notes functionality

## Features
- Add, view, edit, and delete notes
- Search notes by title or content
- Choose a colour for each note
- Save notes in browser localStorage

## Run
Open `index.html` in a modern browser with an internet connection. React, ReactDOM, and Babel are loaded from CDNs.
